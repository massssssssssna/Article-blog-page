# The Fatima Gazette | Snapchat Gaming Legend

An interactive editorial chronicle celebrating Urooj Fatima's legendary Snapchat streak records, reflex arcade dominance, and pop culture footprint.

## Tech Stack
- **Framework**: Next.js 16 (Turbopack)
- **UI Library**: React 19
- **Icons**: Lucide React
- **Audio**: Web Audio API Sound Synthesizer
- **Animations**: Canvas Particle Engine & Canvas Confetti

## Getting Started
```bash
npm install
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000) in your browser.
